    Программа и проверка

      Выгрузка и публикация

      Оба файла данных нужно опубликовать вместе. Уже начавшиеся показы защищены от изменения.

      1. Скачайте оба файла после окончательной проверки.
      2. Откройте папку data в GitHub.
      3. Загрузите videos.json и schedule.json вместе и сохраните одним коммитом.
      4. Дождитесь публикации GitHub Pages. Открытый эфир получит новую программу автоматически.

      Редактор не запрашивает и не хранит токены GitHub. Резервная копия содержит каталог и расписание в одном файле для последующего импорта.
