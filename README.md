# Документальное телевидение · 0.2.0

Статический телеканал: единая программа по времени Минска (UTC+3), GitHub Pages из main / root. Видеопоток идёт от источника напрямую к зрителю. Сервер приложения и сборщик не нужны.

## Возможности

- Телевизор с сохранением исходной обрезки YouTube сверху и снизу: assets/style.css не изменён.
- Текущее время передачи, остаток и полоса прохождения; полная программа по датам и ближайшей неделе.
- Заставка с часами, анонсом и обратным отсчётом между передачами и после окончания дня.
- Автоматическая синхронизация при отставании более восьми секунд, не чаще раза в 30 секунд; проверка после возврата на вкладку.
- После 25 секунд без прогресса или ошибки — до двух повторных подключений с задержкой 4 и 15 секунд. Кнопка повторной попытки позволяет попробовать снова. Технические состояния поверх эфира не показываются.
- После фактического окончания ролика показывается заставка до следующей передачи: эфирная сетка не сдвигается.
- Сохранение громкости, mute и резервной программы в localStorage.
- Часы опираются на Date/Age ответа программы и монотонный таймер, если заголовки доступны и ответ пришёл за три секунды. Иначе используется исходное время устройства. Это приблизительная синхронизация, не гарантия покадрового совпадения; YouTube-реклама, буферизация и ограничения браузера могут влиять на просмотр.
- Полноэкранные кнопки скрываются через три секунды; движение указателя, касание или клавиатура возвращают их. Фокус на кнопках удерживает их видимыми.
- Архив с поиском, разделами, просмотром с начала и ссылками на оригиналы.
- Поддержка YouTube и прямых HTTPS-видеофайлов. Совместимость кодека, доступность и поддержка перемотки зависят от сервера источника. Для прямых файлов используется полный кадр; обрезка YouTube сохранена.

## Программа

Ранее опубликованные показы 6 октября сохранены, включая исторический порядок серий 11 / 10. С 7 по 13 октября 2026 года в 20:00 — последовательные повторы «Цивилизации», две серии за вечер, в последний день одна. Пауза внутри блока — 30 секунд. Бесконечного повтора нет.

Каталог: `data/videos.json`. Обязательные поля: уникальный ключ, title, durationSeconds, source (`type: youtube, videoId` или `type: file, url`). Необязательные: series, episode, year (строка), country, author, category, summary, archive, sourceUrl. Все сведения о передачах хранятся в каталоге.

Программа: `data/schedule.json`, programs с id, video, start, end, необязательными theme и repeat. Даты обязаны включать часовой пояс. Интервалы полуоткрытые: начало включено, конец исключён. Продолжительность показа не должна превышать длительность видео. Пересечения запрещены, паузы разрешены.

## Редактор

Откройте `editor.html` на опубликованном сайте. Он читает программу, но не изменяет репозиторий сам.

1. Выберите передачу либо «Новая передача». Заполните источник, фактическую длительность и описание. Сохраните.
2. Выберите начало будущего блока по Минску, паузу, название тематического вечера и отметку повтора.
3. Добавьте отдельные передачи или цикл целиком. Порядок меняется перетаскиванием либо кнопками ↑ / ↓.
4. Добавьте блок в программу. Проверьте все даты, предупреждения о паузах и порядке серий.
5. Скачайте videos.json и schedule.json после окончательной правки. Загрузите их вместе в папку data одним коммитом через GitHub. Не редактируйте программу между скачиванием этих двух файлов.

Черновик автоматически сохраняется в этом браузере; кнопка «Открыть черновик» восстанавливает его. Резервная копия экспортируется одним JSON и импортируется в редактор. Можно импортировать и оба отдельных файла одновременно. Программа, которая уже началась, защищена при редактировании/экспорте, и отдельно при обновлении работающего эфира. Смена edition не отменяет эту защиту. После внешней публикации сначала загрузите актуальную опубликованную программу в редакторе.

Для переноса будущего блока удалите его будущие показы и соберите заново с нужным временем. Никакие токены или пароли не хранятся в редакторе. Прямой публикации из браузера без отдельной авторизации нет.

## Проверки и разработка

Node.js 22+: `npm test` и `npm run check`. Зависимостей нет. GitHub Actions запускает проверки на push и PR. Проверки данных не гарантируют доступность удалённых видео; оригинальные источники проверяются отдельно перед назначением.

Для локального просмотра: `python -m http.server 8000`, затем http://localhost:8000. Открытие через file:// не поддерживается (JSON загружается через fetch).

Основные модули:
- assets/schedule.js — проверка данных, защита истории, часы, загрузка и кеш.
- assets/media.js — адаптеры YouTube / HTML video.
- assets/player.js — эфир и телепрограмма.
- assets/common.js — форматирование и карточки.
- assets/archive.js, assets/editor.js — архив и редактор.
- assets/features.css — дополнительные стили, без изменения исходного файла обрезки.

Новые направления можно добавлять через разделы и тематические блоки: научпоп, история, музыка, авторские выпуски. Используйте собственные материалы или источники, для которых допустим выбранный способ показа.
