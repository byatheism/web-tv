# Музыкальное телевидение

Один канал с YouTube-видео по фиксированной программе. Сайт публикуется через GitHub Pages: main, / (root).

## Файлы
- index.html — разметка.
- assets/style.css — оформление.
- assets/player.js — плеер, звук и управление.
- assets/schedule.js — загрузка, проверка и выбор показа.
- data/videos.json — каталог видео.
- data/schedule.json — конкретные показы с датами начала и конца.

## Обновление программы
Добавьте запись в videos.json с уникальным внутренним ID, title, durationSeconds и source.type=youtube/source.videoId. Добавьте будущий показ в schedule.json: уникальный id, video (ID каталога), start и end с часовым поясом. При изменении версии каталога синхронно измените catalogVersion расписания. Публикуйте оба JSON в одном коммите.

Не меняйте уже начавшиеся показы. Открытая страница отклоняет такие обновления. Изменение опубликованной истории всё равно повлияет на новых посетителей: это правило должен соблюдать редактор. Не удаляйте видео, на которые ссылается расписание. Пересечения, отсутствующие видео и некорректные длительности отклоняются. Перерывы допускаются.

Данные проверяются раз в 60 секунд с no-cache. При ошибке сохраняется последняя рабочая программа; после перезагрузки возможен её резерв из localStorage. Текущий показ не перезапускается при обновлении будущих записей или возврате на вкладку. Начало и конец берутся из расписания, а не из изменяемого цикла.

Сейчас назначены 14 показов до 2026-10-06 06:47:48 +03:00. Бесконечного повтора нет. Для продолжения добавьте следующие показы заранее.

Громкость и mute сохраняются под прежним ключом web-tv:sound. Время берётся с устройства зрителя. Реклама и буферизация YouTube могут нарушать синхронизацию. На собственные файлы плеер пока не переведён.

Расчёт интервалов проверен; реальное воспроизведение и развёртывание новой версии в браузере ещё требуют проверки.
