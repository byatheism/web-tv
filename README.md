# Документальное телевидение · 0.3.0

Статический одноканальный сайт с общей программой по времени Минска (UTC+3). Сайт публикуется через GitHub Pages из ветки `main`. Видеопоток идёт напрямую от источника к зрителю.

## Эфир

- YouTube-видео и прямые HTTPS-видеофайлы воспроизводятся как единый телеканал.
- Сохранена исходная обрезка YouTube сверху и снизу в `assets/style.css`.
- Между передачами эфир ждёт следующую отметку, кратную пяти минутам. Если видео закончилось в 12:46:36, следующий показ начнётся в 12:50.
- За пять секунд до начала показывается короткая заставка DOC TV с названием следующей передачи.
- Первый показ видео, которое раньше не выходило на канале, автоматически получает отметку «ПРЕМЬЕРА».
- Настройки громкости и mute сохраняются в `localStorage`.
- Плеер восстанавливается после ошибок и возврата на вкладку без лишнего пересоздания, если текущее воспроизведение ещё исправно.

## Автоматическая программа

`data/schedule.json` содержит только уже опубликованную историю/текущий показ и правила будущей ротации. Будущая сетка строится автоматически в `assets/schedule.js`.

Ротация:
- чередует независимые группы передач и не ставит одну группу два раза подряд;
- продолжает сериалы с серии, следующей за последней уже показанной;
- для обычных подборок выбирает наиболее давно не показывавшееся видео;
- не повторяет одну и ту же серию раньше заданного интервала (`minRepeatHours`, сейчас 8 часов);
- автоматически подхватывает новые серии существующих документальных циклов;
- строит программу минимум на семь суток вперёд при каждой загрузке/обновлении страницы;
- всегда округляет начало следующего показа вверх до следующей 5-минутной отметки.

Сейчас в ротации только два документальных цикла: «Цивилизация» и «Великие географические открытия». Музыкальные видео из каталога удалены.

Каталог передач хранится в `data/videos.json`. Обязательные поля: `title`, `durationSeconds`, `source`. Для циклов используются `series` и `episode`.

## Интерфейс

Корпус телевизора, рамка экрана, акустическая решётка, кнопки и регулятор громкости оформлены как аппаратные элементы. Короткая заставка перед передачей и экран перерыва находятся поверх плеера, но не меняют исходную обрезку YouTube.

## Проверки и разработка

Node.js 22+:

```
npm test
npm run check
```

Проверки контролируют пересечения, пятиминутные стартовые отметки, порядок серий, ротацию, премьеры и защиту от слишком частых повторов. GitHub Actions запускает их при каждом изменении.

Основные модули:
- `assets/schedule.js` - проверка данных и автоматический составитель программы;
- `assets/media.js` - YouTube / HTML video;
- `assets/player.js` - эфир, заставки и восстановление воспроизведения;
- `assets/common.js` - общие функции интерфейса;
- `assets/style.css` - корпус телевизора и исходная обрезка YouTube;
- `assets/features.css` - заставки, премьеры и дополнительные стили.
