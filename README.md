# Документальное телевидение · 0.2.5

Статический одноканальный сайт с общей программой по времени Минска (UTC+3). Сайт публикуется через GitHub Pages из ветки `main`. Видеопоток идёт напрямую от источника к зрителю.

## Возможности

- Воспроизведение YouTube-видео и прямых HTTPS-видеофайлов по единому расписанию.
- Сохранена исходная обрезка YouTube сверху и снизу в `assets/style.css`, чтобы скрывать элементы интерфейса плеера.
- Текущая передача, оставшееся время, полоса прохождения и ближайшие передачи.
- Заставка с часами и анонсом следующего показа во время перерывов.
- Восстановление воспроизведения после ошибок и возврата на вкладку без принудительного пересоздания плеера, если это не требуется.
- Проверка рассинхронизации и корректировка позиции только при заметном отклонении.
- Часы сайта используют время устройства зрителя.
- Сохранение громкости и mute в `localStorage`.
- Полноэкранный режим со скрытием панели управления после бездействия.

## Программа

Каталог передач хранится в `data/videos.json`.

Обязательные поля видео:
- `title`
- `durationSeconds`
- `source`: YouTube (`type: youtube`, `videoId`) либо прямой HTTPS-файл (`type: file`, `url`)

Дополнительные поля могут содержать название цикла, номер серии, автора, страну, год, категорию и краткое описание.

Расписание хранится в `data/schedule.json`. Каждый показ содержит уникальный `id`, ссылку на видео из каталога, `start` и `end` с часовым поясом. Пересечения запрещены, паузы разрешены. Уже начавшиеся показы защищены от изменения при обновлении открытого эфира.

## Проверки и разработка

Node.js 22+:

```
npm test
npm run check
```

GitHub Actions запускает проверки при изменениях.

Для локального просмотра:

```
python -m http.server 8000
```

Основные модули:
- `assets/schedule.js` — загрузка и проверка программы;
- `assets/media.js` — YouTube / HTML video;
- `assets/player.js` — логика эфира;
- `assets/common.js` — общие функции интерфейса;
- `assets/style.css` — основной вид телевизора и обрезка YouTube;
- `assets/features.css` — дополнительные стили интерфейса.
